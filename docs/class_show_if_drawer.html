Detailed Description

Inspector drawer for ShowIfAttribute that conditionally shows or hides a serialized field based on the value of a boolean sibling/parent property.

@thread Unity Editor thread only. Editor-only script, excluded from player builds via UNITY_EDITOR.

Behavior:

  • If the referenced condition property is found and is a bool, the decorated field is only drawn when its value equals ShowIfAttribute.RequiredState (default: true).
  • If the condition cannot be found or is not a boolean, the field is shown (fails open).

Field path resolution:

  • First attempts a sibling/ancestor-relative lookup by replacing the tail of property.propertyPath with the condition field name.
  • Falls back to a root-level lookup using just ShowIfAttribute.Field.

Usage:

public class Example : MonoBehaviour
{
[SerializeField] private bool advancedMode;
[SerializeField, ShowIf(nameof(advancedMode))]
private float advancedSetting;
}
