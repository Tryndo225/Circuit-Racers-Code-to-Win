Detailed Description

UI entry representing a single saved level row.

Displays the best time, allows selecting the level for play, and removing it from saved data.

@thread Unity main thread.

Invariant
levelTime (if assigned) is used only for UI text updates.
levelData may be null until SetUp(GameDataManager.LevelData) is called.
