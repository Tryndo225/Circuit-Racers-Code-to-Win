Detailed Description

UI entry representing a single saved level row.

Displays saved level metadata and exposes UI actions for selecting, renaming, exporting, and deleting the level.

This component is used by saved-level lists. Each entry receives a GameDataManager.LevelData object through SetUp(GameDataManager.LevelData) and uses it to populate the level name, best time, day/night icon, and optional preview.

Unity lifecycle note:

  • MonoBehaviour constructors are not used for normal Unity initialization.
  • Runtime setup should be done through SetUp(GameDataManager.LevelData).
