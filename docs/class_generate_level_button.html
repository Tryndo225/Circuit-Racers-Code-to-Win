Detailed Description

Strategy: procedurally generate a level (optionally circuit), add checkpoints, and display it in a popup preview.

@ Workflow:

  • Reads UI sliders/toggles to update generation parameters.
  • Runs generation and checkpoint placement on background threads via Task.Run.
  • On success, shows the result in LevelPopUp attached to popUp.

Threading:

  • Kicks off CPU work on background threads; UI interactions remain on main.

Invariants:

  • popUp must reference a GameObject with a LevelPopUp component.
