Detailed Description

Button strategy that procedurally generates a level, creates checkpoints, and displays the result in a popup preview.

Workflow:

  • Reads current size/circuit settings from the assigned UI controls.
  • Generates a LevelMap using LevelGenerator.
  • Adds checkpoint data using LevelCheckPointMaker.
  • Displays the generated level through a LevelPopUp component on popUp.

Threading:

  • Generation and checkpoint placement are run through Task.Run to avoid blocking the UI.
  • Unity object access remains in the surrounding async UI action.

Requirements:

  • popUp must reference a GameObject with a LevelPopUp component.
  • sizeSlider and createCircuitsToggle are optional; if left unassigned, the serialized default values are used.
