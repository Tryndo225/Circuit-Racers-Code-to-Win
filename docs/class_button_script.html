Detailed Description

Generic UI button driver that delegates its click behavior to a pluggable ButtonType.

Keeps scene/UI logic decoupled by holding a serialized strategy object that implements ButtonType.Action.

Usage:

  • Assign a ButtonType (e.g., ChangeSceneButton, GenerateLevelButton) in the Inspector.
  • Hook the Unity Button's OnClick() to OnButtonClick (or call it from a UnityEvent).

Threading:

  • Unity main thread for OnButtonClick; specific strategies may spawn background work (see GenerateLevelButton).
