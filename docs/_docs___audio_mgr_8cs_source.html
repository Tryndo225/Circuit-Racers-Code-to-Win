2 * @file Docs_AudioMgr.cs
3 * @brief Documentation entry for the Audio Manager subsystem.
4 *
5 * @defgroup audio_mgr Audio Manager
6 * @ingroup systems
7 * @brief Centralized music and SFX playback with pooling, per-clip reuse, and low-pass control.
8 *
9 * @details
10 * The Audio Manager is implemented by ::SoundManager (a Singleton<SoundManager>).
11 * It provides a single looping music source (with an AudioLowPassFilter) and a lightweight,
12 * allocation-friendly SFX layer built on pooled ::SoundManagerHelper instances. SFX can be
13 * played as 2D or 3D, reused per clip, paused/reset/stopped, and "continued" for a short
14 * tail using a grace timer.
15 *
16 * Contents:
17 * - see audio_mgr_overview
18 * - see audio_mgr_inspector
19 * - see audio_mgr_lifecycle
20 * - see audio_mgr_usage
21 * - see audio_mgr_api
22 * - see audio_mgr_integration
23 * - see audio_mgr_performance
24 * - see audio_mgr_troubleshooting
25 * - see audio_mgr_versions
26 *
27 * ----------------------------------------------------------------------
28 * @section audio_mgr_overview Overview
29 *
30 * Responsibilities:
31 * - Music: single AudioSource for background music, optional low-pass control.
32 * - SFX: pooled helpers keyed by AudioClip for reuse and minimal allocations.
33 * - Routing: optional AudioMixerGroup for music and SFX.
34 * - Listener-follow: manager and helpers follow Camera.main position each frame.
35 *
36 * Dependencies:
37 * - Generic.Singleton<T> base type.
38 * - ::SoundManagerHelper (pooled SFX player component).
39 * - UnityEngine.Audio for AudioMixerGroup and filters.
40 *
41 * Threading:
42 * - Unity main thread. Initialization in Awake(), maintenance in Update().
43 *
44 * Invariants:
45 * - Exactly one ::SoundManager instance is active (enforced by Singleton).
46 * - Pooled helpers are reused; free helpers are marked IsUsed == false.
47 *
48 * ----------------------------------------------------------------------
49 * @section audio_mgr_inspector Inspector (SoundManager)
50 *
51 * Fields:
52 * - musicVolume (float, 0..1): master music volume.
53 * - sfxVolume (float, 0..1): global SFX multiplier applied to all SFX plays.
54 * - musicMixerGroup (AudioMixerGroup): optional bus for music.
55 * - sfxMixerGroup (AudioMixerGroup): optional bus for SFX.
56 * - continueThreshold (float, seconds): grace period for ContinueSFXClip before auto-stop.
57 *
58 * Internals created at runtime:
59 * - One AudioSource for music (looping).
60 * - One AudioLowPassFilter (exposed via SoundManager::MusicLowPass).
61 * - A pool of SoundManagerHelper objects for SFX (created on demand).
62 *
63 * ----------------------------------------------------------------------
64 * @section audio_mgr_lifecycle Lifecycle
65 *
66 * Awake:
67 * - Creates and configures the music AudioSource and AudioLowPassFilter.
68 * - Reads initial volumes from inspector.
69 *
70 * Update:
71 * - Tracks Camera.main; sets manager transform to the camera position.
72 * - Mirrors manager position to all pooled SFX helpers.
73 * - Services "continue" timers and auto-stops expired looping SFX; unmaps them.
74 *
75 * ----------------------------------------------------------------------
76 * @section audio_mgr_usage Usage
77 *
78 * Quick start (music):
79 * @code{.cs}
80 * public class TitleMusic : MonoBehaviour
81 * {
82 * public AudioClip theme;
83 * void Start()
84 * {
85 * SoundManager.Instance.PlayMusic(theme);
86 * SoundManager.Instance.SetMusicVolume(0.7f);
87 * }
88 * }
89 * @endcode
90 *
91 * 3D SFX on a Transform:
92 * @code{.cs}
93 * // One-shot crash at impact point
94 * SoundManager.Instance.PlaySFXClip(crashClip, hitTransform,
95 * volume: 1.0f, pitch: 1.0f, loop: false, specialBlend: 1.0f, reset: true);
96 * @endcode
97 *
98 * Looping engine layer with reuse:
99 * @code{.cs}
100 * // Start looping (no reset if already playing this clip)
101 * SoundManager.Instance.PlaySFXClip(engineLoop, carTransform,
102 * volume: 0.8f, pitch: 1.0f, loop: true, specialBlend: 1.0f, reset: false);
103 *
104 * // Later: pause / reset / stop
105 * SoundManager.Instance.PauseSFXClip(engineLoop);
106 * SoundManager.Instance.ResetSFXClip(engineLoop); // rewind to start
107 * SoundManager.Instance.StopSFXClip(engineLoop);
108 * @endcode
109 *
110 * "Continue" tail:
111 * @code{.cs}
112 * // Keeps playing for continueThreshold seconds after last call, then auto-stops.
113 * SoundManager.Instance.ContinueSFXClip(skidLoop);
114 * SoundManager.Instance.ContinueSFXClip(skidLoop, 0.6f); // explicit start volume
115 * @endcode
116 *
117 * Music duck or muffle:
118 * @code{.cs}
119 * var lp = SoundManager.Instance.MusicLowPass;
120 * lp.cutoffFrequency = 1200f; // muffle during pause
121 * // restore later to 22000f
122 * @endcode
123 *
124 * ----------------------------------------------------------------------
125 * @section audio_mgr_api Public API Reference
126 *
127 * Properties:
128 * - AudioLowPassFilter MusicLowPass: access the music low-pass component.
129 *
130 * Music:
131 * - void PlayMusic(AudioClip clip): starts or resumes looping music for clip.
132 * - void StopMusic(): stops the current music source if playing.
133 * - void SetMusicVolume(float volume01): sets the [0..1] music volume.
134 *
135 * SFX (pooled per-clip):
136 * - void PlaySFXClip(AudioClip clip): plays at manager position (2D by default).
137 * - void PlaySFXClip(AudioClip clip, float volume): same with starting volume.
138 * - void PlaySFXClip(AudioClip clip, Transform transform): plays spatially at a target.
139 * - void PlaySFXClip(AudioClip clip, Transform transform,
140 * float volume = 1f, float pitch = 1f,
141 * bool loop = false, float specialBlend = 0.0f, bool reset = true):
142 * Plays or loops with full control.
143 * specialBlend = 0 for 2D, 1 for fully 3D.
144 * If this clip is already mapped:
145 * - reset == true: rewinds and plays from the start.
146 * - reset == false: resumes/continues if available.
147 * - void ContinueSFXClip(AudioClip clip): loops and schedules auto-stop after continueThreshold seconds since last call.
148 * - void ContinueSFXClip(AudioClip clip, float volume): same with explicit starting volume.
149 * - void PauseSFXClip(AudioClip clip): pauses a mapped clip.
150 * - void ResetSFXClip(AudioClip clip): rewinds a mapped clip to time = 0.
151 * - void StopSFXClip(AudioClip clip): stops and unmaps the helper for this clip.
152 * - void SetSFXVolume(float volume01): sets global SFX multiplier (affects subsequent plays).
153 *
154 * Notes:
155 * - All SFX are routed through sfxMixerGroup if assigned.
156 * - The internal SoundManagerHelper applies pitch, spatial blend, looping, and 3D rolloff.
157 *
158 * ----------------------------------------------------------------------
159 * @section audio_mgr_integration Integration Notes
160 *
161 * Vehicle systems:
162 * - Pair engine audio with transmission events by calling EngineSound.OnShift().
163 * - Use ContinueSFXClip for short-lived loop tails (for example, skid).
164 *
165 * UI:
166 * - Use PlaySFXClip(clip) overloads for non-positional UI feedback.
167 *
168 * Scene setup:
169 * - Ensure a single AudioListener exists (usually on the main camera).
170 *
171 * ----------------------------------------------------------------------
172 * @section audio_mgr_performance Performance and GC
173 *
174 * - SFX helpers are pooled and reused per clip to minimize allocations.
175 * - Avoid calling ContinueSFXClip every frame for the same clip unless you want to extend the tail.
176 * - Keep continueThreshold small (about 0.1 to 0.25 s) to prevent build-up.
177 *
178 * ----------------------------------------------------------------------
179 * @section audio_mgr_troubleshooting Troubleshooting
180 *
181 * - No sound: check mixer routing, ensure an AudioListener exists, and verify volumes > 0.
182 * - Multiple managers: only one SoundManager should be active (Singleton prevents duplicates).
183 * - Clip does not stop: repeated ContinueSFXClip calls refresh the timer; reduce calls or use StopSFXClip.
184 *
185 * ----------------------------------------------------------------------
186 * @section audio_mgr_versions Version History
187 *
188 * - v1.1: Pooled helpers, per-clip mapping, ContinueSFXClip, MusicLowPass.
189 * - v1.0: Basic music and SFX playback with volumes and mixer routing.
190 */
