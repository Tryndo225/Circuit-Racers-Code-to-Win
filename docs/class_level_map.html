Detailed Description

Serializable level definition for a grid-based race track.

Stores track dimensions, metadata, start/finish positions, lap settings, day/night state, and tile data.

Tile values are defined by LevelTileTypes:

  • LevelTileTypes.CP: checkpoint.
  • LevelTileTypes.Spacer: spacer.
  • LevelTileTypes.Grass: empty/grass.
  • LevelTileTypes.Track: road.
  • LevelTileTypes.PlaceHolder and higher values: temporary placeholders used during generation.

The runtime tile grid is stored in Tiles. Because Unity does not serialize rectangular 2D arrays directly, tilesFlat is used as a flattened serialization representation.

int [,] LevelMap.Tiles

Runtime 2D tile grid.

Tile values are represented by LevelTileTypes:

  • LevelTileTypes.CP = checkpoint.
  • LevelTileTypes.Spacer = spacer.
  • LevelTileTypes.Grass = empty/grass.
  • LevelTileTypes.Track = road.
  • LevelTileTypes.PlaceHolder and higher values = temporary placeholders used during generation.

This field is not serialized directly. It is flattened into tilesFlat before serialization and rebuilt from tilesFlat after deserialization.
