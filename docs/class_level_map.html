Detailed Description

Serializable level definition for a grid-based track: dimensions, circuit flag, endpoints, and a 2D tile map with Unity-friendly flatten/unflatten for serialization.

Tile codes: -2 = checkpoint, -1 = spacer, 0 = empty/grass, 1 = road, 2+ = BFS placeholders during generation.

Invariant
Tiles size equals Width × Height when present. @thread Unity main thread for Unity serialization callbacks.
