Detailed Description

Scene-local singleton base for Unity components.

Template Parameters
TConcrete type deriving from SceneSingleton<T>.

Ensures a single instance in the active scene without preserving it across scene loads.

This class keeps the singleton coalescing behaviour from Singleton<T>, but disables UnityEngine.Object.DontDestroyOnLoad(UnityEngine.Object) persistence.
