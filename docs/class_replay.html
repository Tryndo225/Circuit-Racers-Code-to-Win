Detailed Description

Serializable race replay containing an ordered list of recorded ReplaySnapshot values.

Stores replay duration metadata and the recorded snapshots used for replay playback or preview.

A replay can be built incrementally with AddSnapshot, copied with Copy, or cleared with Reset.
