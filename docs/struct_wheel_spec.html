Detailed Description

Serializable wheel specification used by VehicleController.

Stores the collider, visual wheel transform, and drive/steer flags for one vehicle wheel.

The vehicle controller expects four entries in front-left, front-right, rear-left, rear-right order. Each entry is later unpacked and passed to DriveTrainController during setup.
