Detailed Description

UI speedometer that displays the current speed as both a gauge value and a numeric text label.

Reads speed from the selected source and mirrors it into a slider-based gauge.

The component supports reading speed from either a live DriveTrainController or from ReplayPreviewer playback, depending on source.

The slider is used as a visual gauge only and is made non-interactable in Awake.
