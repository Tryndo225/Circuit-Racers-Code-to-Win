2 * @file Docs_CoreUtils.cs
3 * @brief Documentation entry for shared runtime utility types.
4 *
5 * @defgroup core_utils Core Utilities
6 * @ingroup systems
7 * @brief Small shared helpers for commands, layer masks, content hashing, singletons, and serializable dictionaries.
8 *
9 * @details
10 * The Core Utilities group contains reusable runtime helpers used across multiple systems.
11 * These types are intentionally small and independent so they can support scene management,
12 * game data, track management, UI actions, and editor-facing serialized data without creating
13 * large dependencies.
14 *
15 * Main utilities:
16 * - ::SerializableRunnable provides a serializable command base with a Run entry point.
17 * - ::LayerMaskUtils adds LayerMask helper methods.
18 * - IEnumerableExtensions::IEnumerableExtensions provides content hashing for sequences.
19 * - Generic::Singleton<T> provides persistent singleton behaviour.
20 * - Generic::SceneSingleton<T> provides scene-local singleton behaviour.
21 * - ::SerializableDictionary<TKey, TValue> provides a Unity-serializable dictionary wrapper.
22 *
23 * Contents:
24 * - @ref core_utils_overview
25 * - @ref core_utils_runnable
26 * - @ref core_utils_layer_masks
27 * - @ref core_utils_hashing
28 * - @ref core_utils_singletons

35 * ----------------------------------------------------------------------
36 * @section core_utils_overview Overview
37 *
38 * Responsibilities:
39 * - Provide common runtime patterns used by multiple subsystems.
40 * - Keep command-like serialized actions simple and callable.
41 * - Provide readable LayerMask checks.
42 * - Provide an order-sensitive content hash for enumerable sequences.
43 * - Provide singleton bases for persistent and scene-local managers.
44 * - Provide a serializable dictionary implementation compatible with Unity serialization.
45 *
46 * Threading:
47 * - Singleton and scene singleton lifecycle methods are Unity main thread only.
48 * - SerializableRunnable callbacks are Unity serialization callbacks.
49 * - SerializableDictionary serialization callbacks are Unity serialization callbacks.
50 * - IEnumerableExtensions::GetContentHash is pure C# code but should still be used with stable,
51 * non-mutating sequences during the call.
52 *
53 * ----------------------------------------------------------------------
54 * @section core_utils_runnable SerializableRunnable
55 *
56 * ::SerializableRunnable is an abstract base class for serializable command objects.
57 *
58 * Responsibilities:
59 * - Expose a required Run() method.
60 * - Provide overridable Unity serialization callbacks.
61 * - Allow derived command objects to be stored in serialized fields and executed later.
62 *
63 * Typical use:
64 * - Scene actions.
65 * - Button strategies.
66 * - Small command objects configured in the Inspector.
67 *
68 * Behaviour:
69 * - Derived classes must implement Run().
70 * - OnBeforeSerialize() is virtual and empty by default.
71 * - OnAfterDeserialize() is virtual and empty by default.
72 *
73 * ----------------------------------------------------------------------
74 * @section core_utils_layer_masks LayerMask Utilities
75 *
76 * ::LayerMaskUtils contains extension helpers for Unity LayerMask values.
77 *
78 * Contains:
79 * - Checks whether a LayerMask includes a given layer index.
80 * - Uses bitwise mask checking.
81 *
82 * Example:
83 * @code{.cs}
84 * if (ignoreLayers.Contains(collision.gameObject.layer))
85 * {
86 * return;
87 * }
88 * @endcode
89 *
90 * ----------------------------------------------------------------------
91 * @section core_utils_hashing Enumerable Content Hashing
92 *
93 * IEnumerableExtensions::IEnumerableExtensions provides GetContentHash.
94 *
95 * Purpose:
96 * - Compute an order-sensitive hash from sequence contents.
97 * - Support change detection for collections such as saved level lists.
98 *
99 * Behaviour:
100 * - Returns zero for null sequences.
101 * - Uses EqualityComparer<T>.Default when no comparer is supplied.
102 * - Uses System.HashCode aggregation.
103 * - Includes element order in the resulting hash.
104 *
105 * Limitations:
106 * - Intended for runtime/session change detection.
107 * - Not intended as a persistent identity.
108 * - Hash values may differ across runtime versions or platforms.
109 *
110 * ----------------------------------------------------------------------
111 * @section core_utils_singletons Singletons
112 *
113 * Generic::Singleton<T>:
114 * - Provides a minimal persistent singleton base for MonoBehaviours.
115 * - The first instance becomes Instance.
116 * - Later duplicates destroy their own GameObject.
117 * - The surviving instance is marked with DontDestroyOnLoad.
118 * - OnDestroy clears Instance when the current object owns it.
119 *
120 * Generic::SceneSingleton<T>:
121 * - Inherits from Generic::Singleton<T>.
122 * - Keeps the coalescing behaviour.
123 * - Overrides persistence so the object remains scene-local.
124 * - Useful for managers that should reset with the scene.
125 *
126 * Execution order:
127 * - Singleton<T> uses DefaultExecutionOrder(-100).
128 * - SceneSingleton<T> uses DefaultExecutionOrder(-50).
129 *
130 * ----------------------------------------------------------------------
131 * @section core_utils_dictionary SerializableDictionary
132 *
133 * ::SerializableDictionary<TKey, TValue> wraps a Dictionary<TKey, TValue> and exposes IDictionary<TKey, TValue>.
134 *
135 * Purpose:
136 * - Unity does not serialize generic Dictionary<TKey, TValue> directly.
137 * - This class mirrors dictionary contents into parallel serialized lists.
138 * - Runtime access goes through the internal Dictionary<TKey, TValue>.
139 *
140 * Serialized backing:
141 * - keys: serialized list of keys.
142 * - values: serialized list of values.
143 *
144 * Serialization:
145 * - OnBeforeSerialize clears the serialized lists and fills them from the runtime dictionary.
146 * - OnAfterDeserialize rebuilds the runtime dictionary from the serialized lists.
147 * - If keys and values have different counts, extra entries are ignored.
148 * - Duplicate keys are ignored during deserialization with a warning.
149 *
150 * Runtime API:
151 * - Implements IDictionary<TKey, TValue>.
152 * - Supports normal dictionary operations such as Add, Remove, ContainsKey, TryGetValue, indexer,
153 * Keys, Values, Count, Clear, and enumeration.
154 *
155 * Optional helpers:
156 * - GetOrAdd creates a value with a factory when the key is missing.
157 * - Set assigns a value and returns the dictionary instance for fluent use.
158 *
159 * ----------------------------------------------------------------------
160 * @section core_utils_api Public API Reference
161 *
162 * ::SerializableRunnable:
163 * - void Run()
164 * Abstract command entry point implemented by derived classes.
165 *
166 * - void OnBeforeSerialize()
167 * Virtual Unity serialization callback.
168 *
169 * - void OnAfterDeserialize()
170 * Virtual Unity deserialization callback.
171 *
172 * ::LayerMaskUtils:
173 * - bool Contains(this LayerMask mask, int layer)
174 * Returns true when the mask contains the provided layer index.
175 *
176 * IEnumerableExtensions::IEnumerableExtensions:
177 * - int GetContentHash<T>(this IEnumerable<T> source, IEqualityComparer<T> comparer = null)
178 * Computes an order-sensitive hash code for a sequence.
179 *
180 * Generic::Singleton<T>:
181 * - static T Instance
182 * Gets the current singleton instance, or null if none has awoken.
183 *
184 * - bool Coalesce()
185 * Attempts to make the object the active singleton instance.
186 *
187 * - void Persist()
188 * Marks the surviving instance as DontDestroyOnLoad in the base implementation.
189 *
190 * Generic::SceneSingleton<T>:
191 * - void Persist()
192 * Overrides persistence with an intentionally empty implementation.
193 *
194 * ::SerializableDictionary<TKey, TValue>:
195 * - TValue this[TKey key]
196 * Gets or sets a dictionary value.
197 *
198 * - ICollection<TKey> Keys
199 * Gets dictionary keys.
200 *
201 * - ICollection<TValue> Values
202 * Gets dictionary values.
203 *
204 * - int Count
205 * Gets the number of entries.
206 *
207 * - bool IsReadOnly
208 * Always false.
209 *
210 * - void Add(TKey key, TValue value)
211 * Adds a key/value pair.
212 *
213 * - bool ContainsKey(TKey key)
214 * Checks whether a key exists.
215 *
216 * - bool Remove(TKey key)
217 * Removes a key.
218 *
219 * - bool TryGetValue(TKey key, out TValue value)
220 * Attempts to read a value by key.
221 *
222 * - void Clear()
223 * Removes all entries.
224 *
225 * - IEnumerator<KeyValuePair<TKey, TValue>> GetEnumerator()
226 * Enumerates dictionary entries.
227 *
228 * - TValue GetOrAdd(TKey key, Func<TValue> factory)
229 * Returns an existing value or creates, stores, and returns a new value.
230 *
231 * - SerializableDictionary<TKey, TValue> Set(TKey key, TValue value)
232 * Sets a value and returns this dictionary.
233 *
234 * ----------------------------------------------------------------------
235 * @section core_utils_integration Integration Notes
236 *
237 * Scene management:
238 * - ::SceneAssetHelper derives from ::SerializableRunnable so scene actions can be run through a shared command shape.
239 *
240 * UI:
241 * - Button strategies can follow the same command-like pattern as SerializableRunnable.
242 *
243 * Game data:
244 * - ::GameDataManager uses IEnumerableExtensions::GetContentHash for level-list change detection.
245 *
246 * Audio, replay, track, and scene managers:
247 * - Manager components can derive from Generic::Singleton<T> or Generic::SceneSingleton<T> depending on
248 * whether they should persist across scene loads.
249 *
250 * Level generation and track placement:
251 * - Serialized dictionaries can be used for editor-friendly mappings such as track-piece legends.
252 *
253 * Editor utilities:
254 * - Custom drawers may depend on SerializableDictionary backing field names keys and values.
255 *
256 * ----------------------------------------------------------------------
257 * @section core_utils_troubleshooting Troubleshooting
258 *
259 * Singleton Instance is null:
260 * - Check that the singleton component exists in the scene.
261 * - Check script execution order if another object accesses it too early.
262 * - Check whether a duplicate destroyed itself before use.
263 *
264 * Scene singleton persists unexpectedly:
265 * - Use Generic::SceneSingleton<T>, not Generic::Singleton<T>.
266 * - Verify the derived class does not override Persist with DontDestroyOnLoad.
267 *
268 * Duplicate singleton warnings or missing manager:
269 * - Keep only one intended instance in bootstrap/menu scenes.
270 * - Avoid placing persistent singletons in every scene unless duplicate destruction is expected.
271 *
272 * SerializableDictionary loses entries:
273 * - Check for duplicate keys in serialized data.
274 * - Check whether keys and values lists have different lengths.
275 * - Check that key and value types are Unity-serializable.
276 *
277 * Dictionary drawer breaks:
278 * - Confirm the serialized backing fields are still named keys and values.
279 *
280 * Content hash does not change:
281 * - Ensure the compared objects implement meaningful Equals and GetHashCode.
282 * - Remember that hash values are only a change signal, not a stable identity.
283 *
284 * LayerMask check fails:
285 * - Pass a layer index, not a layer mask value.
286 * - Use gameObject.layer as the layer argument.
287 *
288 * ----------------------------------------------------------------------
