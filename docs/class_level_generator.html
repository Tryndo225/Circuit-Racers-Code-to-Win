Detailed Description

Procedural level generator for circuit and point-to-point tracks.

Produces validated LevelMap instances by carving connected roads through a tile grid.

The generator starts from a random start position, prepares an initial opening, repeatedly chooses target points, uses a flood-fill search to find paths, backtracks those paths into road tiles, and applies spacer tiles around roads to keep generated roads separated.

Circuit maps are closed by connecting the last generated road point back to the start point. Generated maps are checked with LevelMapValidator before being returned.

Tile values used by the generator come from LevelMap.LevelTileTypes:

  • LevelMap.LevelTileTypes.Grass: empty tile.
  • LevelMap.LevelTileTypes.Track: road tile.
  • LevelMap.LevelTileTypes.Spacer: spacer tile used to keep roads separated.
  • LevelMap.LevelTileTypes.CP: checkpoint tile, reserved for later checkpoint generation.
  • LevelMap.LevelTileTypes.PlaceHolder and higher values: temporary flood-fill placeholders.

Threading:

  • The generator is CPU-only and does not use Unity scene objects.
  • It mutates the LevelMap and tile arrays it owns or receives, so callers should not share the same map instance across threads.
