Detailed Description

Procedural level generator (static).

Produces circuit or point-to-point tracks using iterative target selection, BFS “flooding”, backtracking to carve roads, and spacing rules.

Tiles semantics: 1 = road, 0 = empty, -1 = spacer, -2 = checkpoint, 2+ = BFS placeholders. @thread Use on Unity main thread (operates on shared map arrays).
