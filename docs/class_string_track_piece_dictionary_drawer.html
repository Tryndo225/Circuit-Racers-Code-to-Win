Detailed Description

Custom inspector drawer for StringTrackPieceDictionary that presents a reorderable, foldout-friendly key/value list (string -> TrackPiece).

Features:

  • Uses ReorderableList for drag reordering, add/remove, and custom element drawing.
  • Keeps the hidden keys and values backing arrays strictly in sync (size & order).
  • Prevents duplicate keys at edit time with a simple dialog warning.
  • Draws the value (TrackPiece) generically, including prefab, position, and rotation fields. Threading: Unity Editor thread only; excluded from player builds by #if UNITY_EDITOR.
