Detailed Description

Controls vehicle lights (front, day, rear, reverse, brake) with optional fading, color/intensity presets, and runtime toggles.

Reverse and brake lights can share bulbs with rear lights and will restore rear light settings when deactivated.

@thread Unity main thread (coroutines run on the main thread).

Invariant
Lists may be empty but can contain nulls; null entries are skipped.
