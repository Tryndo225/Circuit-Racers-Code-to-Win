2 * @file Docs_TrackManager.cs
3 * @brief Documentation entry for the Track Management subsystem.
4 *
5 * @defgroup track_mng Track Manager
6 * @ingroup systems
7 * @brief Race flow control, checkpoint progression, restart/respawn handling, and player car spawning.
8 *
9 * @details
10 * The Track Manager is implemented by ::TrackManager, a MonoBehaviour placed in the race scene.
11 * It coordinates the runtime race lifecycle: spawning/restarting the player car, checkpoint
12 * activation, lap progression, point-to-point completion, circuit completion, respawn handling,
13 * and camera target assignment.
14 *
15 * The subsystem exposes race-progress properties such as the current lap, next required checkpoint,
16 * finish state, and respawn countdown. Race timing itself is coordinated through ::RaceTimeManager.
17 *
18 * Contents:
19 * - @ref track_mng_overview
20 * - @ref track_mng_inspector
21 * - @ref track_mng_lifecycle
22 * - @ref track_mng_checkpoints
23 * - @ref track_mng_respawn
24 * - @ref track_mng_usage
25 * - @ref track_mng_api
26 * - @ref track_mng_integration
27 * - @ref track_mng_troubleshooting
28 * - @ref track_mng_versions
29 *
30 * ----------------------------------------------------------------------
31 * @section track_mng_overview Overview
32 *
33 * Responsibilities:
34 * - Spawning the player car at a designated spawn transform, with a fallback to the TrackManager transform.
35 * - Wiring the ::FollowCamera target to the spawned car and syncing it after respawns.
36 * - Managing race flow for circuit and point-to-point tracks.
37 * - Tracking checkpoint order and enabling only the next required checkpoint.
38 * - Handling player-initiated respawn and full restart actions through the Unity Input System.
39 * - Starting and ending race timing through ::RaceTimeManager.
40 * - Clearing stale selected level data when a scene-defined track is started without a generated-track placer.
41 *
42 * Dependencies:
43 * - UnityEngine.InputSystem for InputActionProperty-based respawn and restart actions.
44 * - ::CheckPointManager for checkpoint registration, activation, deactivation, and lookup.
45 * - ::CheckPointListener components placed in the scene or generated by the track builder.
46 * - ::RaceTrackPlacer for generated-track setup.
47 * - ::FollowCamera for target assignment and SyncCamera() calls.
48 * - ::RaceTimeManager for race start, lap pass, and race end timing.
49 * - ::GameDataManager for clearing selected level-map state when using scene-defined tracks.
50 *
51 * Threading:
52 * - Unity main thread only.
53 * - Uses MonoBehaviour lifecycle methods, input callbacks, Rigidbody state, and coroutines.
54 *
55 * Invariants:
56 * - Checkpoints are visited in configured order.
57 * - Only the next expected checkpoint is active.
58 * - In circuit mode, checkpoint 0 acts as the lap gate.
59 * - In point-to-point mode, the final checkpoint ends the race.
60 * - Respawn places the car at the last valid checkpoint claim, including position, rotation, and velocities.
61 *
62 * ----------------------------------------------------------------------
63 * @section track_mng_inspector Inspector (TrackManager)
64 *
65 * Spawn:
66 * - CarSpawn (Transform): preferred spawn transform for the player car.
67 * If null, the TrackManager transform is used as a fallback.
68 *
69 * Input Settings:
70 * - respawnLastCheckPoint (InputActionProperty): input action used to respawn at the previous checkpoint.
71 * - restartRace (InputActionProperty): input action used to restart the whole race.
72 * - defaultBindings (bool): if true, default actions and bindings are created in OnValidate().
73 *
74 * Car Prefab Reference:
75 * - carPrefab (GameObject): player car prefab instantiated when the race starts or restarts.
76 * - carSpawnVerticalOffset (float): vertical offset applied when spawning the car.
77 * - carSpawnHorizontalOffset (float): forward/backward offset applied relative to the spawn rotation.
78 *
79 * Track Settings:
80 * - levelMap (levelMap): runtime level map used when the race is started from generated or saved track data.
81 * - isCircuit (bool): true for lap-based circuit races; false for point-to-point races.
82 * - laps (int, ShowIf(isCircuit)): number of laps required to finish a circuit race.
83 *
84 * Respawn Delay:
85 * - respawnDelay (float, 0..5): real-time freeze duration used during respawn.
86 *
87 * Runtime Properties (read-only):
88 * - CurrentLap (int): current lap number.
89 * - TotalLaps (int): configured lap count for circuit races.
90 * - CurrentCheckPointIndex (int): index of the next checkpoint that must be claimed.
91 * - IsRaceFinished (bool): whether the race has ended.
92 * - RespawnTimer (float): visible countdown value during respawn or restart countdowns.
93 *
94 * ----------------------------------------------------------------------
95 * @section track_mng_lifecycle Lifecycle
96 *
97 * OnValidate:
98 * - Optionally creates default input actions and bindings.
99 * - Default respawn bindings: Backspace, Triangle, ButtonNorth.
100 * - Default restart bindings: Delete, Start.
101 *
102 * OnEnable:
103 * - Enables respawn and restart actions.
104 * - Subscribes performed callbacks for respawn and restart input.
105 *
106 * OnDisable:
107 * - Unsubscribes input callbacks.
108 * - Disables respawn and restart actions.
109 *
110 * Start:
111 * - If a ::RaceTrackPlacer exists, generated-track setup is expected and this method returns early.
112 * - Otherwise, clears the currently selected level map through ::GameDataManager.
113 * - Clears and auto-collects scene checkpoints through ::CheckPointManager.
114 * - Starts the race using the scene-defined checkpoint layout.
115 *
116 * FixedUpdate:
117 * - Starts the respawn coroutine when a respawn request is pending.
118 *
119 * Restart flow:
120 * - Restart input starts or restarts the restart countdown coroutine.
121 * - The restart coroutine replaces the car, resets race state, pauses time briefly, and then resumes gameplay.
122 *
123 * ----------------------------------------------------------------------
124 * @section track_mng_checkpoints Checkpoints & Laps
125 *
126 * - Checkpoints are owned and activated through ::CheckPointManager.
127 * - ::TrackManager::CheckPointTaken() is registered as the checkpoint listener callback.
128 * - Only the next expected checkpoint is active.
129 * - When the active checkpoint is claimed, the manager advances the checkpoint index and activates the next one.
130 *
131 * Circuit mode:
132 * - Checkpoint 0 acts as the lap gate.
133 * - The first pass initializes lap progress.
134 * - Later passes call ::RaceTimeManager::LapPassed().
135 * - When the configured lap count has been reached and checkpoint 0 is claimed again, the race finishes.
136 *
137 * Point-to-point mode:
138 * - The race finishes when the final checkpoint is claimed.
139 * - On finish, all checkpoints are deactivated and ::RaceTimeManager::RaceEnd() is called.
140 *
141 * ----------------------------------------------------------------------
142 * @section track_mng_respawn Respawn & Restart
143 *
144 * Respawn:
145 * - If the race is finished, respawn input starts a full restart countdown.
146 * - If the player is before the first checkpoint, respawn becomes a full restart.
147 * - In circuit mode, when the checkpoint index has wrapped to zero after at least one lap,
148 * respawn targets the final checkpoint from the previous lap.
149 * - Otherwise, respawn targets the previous checkpoint.
150 *
151 * Respawn mechanics:
152 * - The pending respawn flag is consumed in FixedUpdate.
153 * - The car Rigidbody interpolation state is temporarily adjusted for a clean teleport.
154 * - The car is moved to the saved checkpoint pose.
155 * - Linear and angular velocities saved by the checkpoint are restored.
156 * - Physics transforms are synchronized.
157 * - The follow camera is synchronized.
158 * - Gameplay is paused for a short real-time countdown using Time.timeScale = 0.
159 *
160 * Restart:
161 * - Destroys the existing car instance if one exists.
162 * - Spawns a new car near CarSpawn, or near the TrackManager transform as fallback.
163 * - Tags the spawned car as Player.
164 * - Assigns the spawned car as the follow-camera target.
165 * - Resets lap, checkpoint, and finish state.
166 * - Calls ::RaceTimeManager::RaceStart().
167 * - Deactivates all checkpoints and activates checkpoint 0.
168 * - Runs a fixed restart countdown while gameplay time is paused.
169 *
170 * ----------------------------------------------------------------------
171 * @section track_mng_usage Usage
172 *
173 * Scene-defined track:
174 * - Place a TrackManager in the race scene.
175 * - Add CheckPointListener objects to the scene.
176 * - Ensure CheckPointManager can auto-collect the checkpoints in the intended order.
177 * - Optionally assign CarSpawn; otherwise the TrackManager transform is used.
178 * - Assign the player car prefab.
179 * - Ensure the main camera has a ::FollowCamera component.
180 * - Start the scene. If no ::RaceTrackPlacer exists, TrackManager starts from the scene-defined checkpoints.
181 *
182 * Generated or saved track:
183 * - A ::RaceTrackPlacer is responsible for generated-track setup.
184 * - When a RaceTrackPlacer exists, TrackManager.Start() returns early.
185 * - The generated-track flow should provide the track layout and call ::TrackManager::StartRace(levelMap).
186 *
187 * Custom inputs:
188 * - Disable defaultBindings.
189 * - Assign respawnLastCheckPoint and restartRace through an Input Actions asset.
190 *
191 * ----------------------------------------------------------------------
192 * @section track_mng_api Public API Reference
193 *
194 * Race control:
195 * - void StartRace(levelMap lvlMap): configures race settings from an optional level map,
196 * wires checkpoint listeners, and starts the restart countdown.
197 * - void CheckPointTaken(): advances checkpoint and lap progression, records lap transitions,
198 * and finishes the race when the required final condition is met.
199 *
200 * Runtime progress:
201 * - int CurrentLap: current lap number.
202 * - int TotalLaps: required lap count for circuit races.
203 * - int CurrentCheckPointIndex: next checkpoint that must be claimed.
204 * - bool IsRaceFinished: whether the race has ended.
205 * - float RespawnTimer: visible countdown value during restart or respawn.
206 *
207 * Internal restart and respawn helpers:
208 * - Respawn(): selects the previous checkpoint or starts a full restart according to race state.
209 * - RespawnCar(int index): restores the car pose and velocities stored by a checkpoint.
210 * - Restart(): replaces the car, resets progress, starts timing, and re-arms checkpoints.
211 * - RestartCoroutine(): performs restart and pauses gameplay during the restart countdown.
212 * - RespawnDelayCoroutine(float delay): performs respawn teleport and pauses gameplay during the respawn countdown.
213 *
214 * ----------------------------------------------------------------------
215 * @section track_mng_integration Integration Notes
216 *
217 * - ::RaceTrackPlacer handles generated-track setup. When it exists, TrackManager.Start() returns early.
218 * - ::CheckPointManager owns the runtime checkpoint list and checkpoint activation/deactivation operations.
219 * - ::CheckPointListener captures respawn position, rotation, linear velocity, and angular velocity.
220 * - ::TrackManager consumes saved checkpoint data during respawn.
221 * - ::FollowCamera must exist on the main camera and support target assignment plus SyncCamera().
222 * - ::RaceTimeManager is responsible for race start, lap pass, and race end timing.
223 * - ::GameDataManager::UnselectLevelMap() is used when starting a scene-defined race so stale selected
224 * level data does not remain active.
225 *
226 * ----------------------------------------------------------------------
227 * @section track_mng_troubleshooting Troubleshooting
228 *
229 * Car not spawning:
230 * - Ensure carPrefab is assigned.
231 * - Verify CarSpawn exists or that the TrackManager transform is a sensible fallback spawn point.
232 * - Check that the spawned prefab has a Rigidbody.
233 *
234 * Checkpoints not advancing:
235 * - Confirm checkpoints were registered in ::CheckPointManager.
236 * - Confirm only the next required checkpoint is active.
237 * - Ensure the player car is tagged "Player".
238 * - Verify each checkpoint listener calls ::TrackManager::CheckPointTaken().
239 *
240 * Respawn puts the car in the wrong place:
241 * - Verify each ::CheckPointListener captures the claim position and rotation correctly.
242 * - Check that checkpoint ordering matches the intended driving order.
243 * - Confirm saved linear and angular velocities are valid.
244 *
245 * Restart behaves like a scene reset but old selected level data remains:
246 * - For scene-defined races, TrackManager.Start() clears the selected level map through ::GameDataManager.
247 * - For generated-track races, setup should be handled by ::RaceTrackPlacer.
248 *
249 * Timer not moving:
250 * - Race time is paused during respawn and restart countdowns with Time.timeScale = 0.
251 * - Ensure the countdown reaches zero and gameplay time is restored.
252 *
253 * Camera not following after restart or respawn:
254 * - Ensure Camera.main exists.
255 * - Ensure the main camera has a ::FollowCamera component.
256 * - Check that the spawned car is assigned as the camera target after restart.
257 *
258 * ----------------------------------------------------------------------
259 * @section track_mng_versions Version History
260 *
261 * - v1.2: Scene-defined race startup clears selected level-map state and auto-collects checkpoints
262 * when no RaceTrackPlacer is present.
263 * - v1.1: Respawn freeze timer and countdown-ready timer added; circuit and point-to-point flows unified.
264 * - v1.0: Basic checkpoints, lap counting, restart, respawn, car spawning, and race flow.
265 */
