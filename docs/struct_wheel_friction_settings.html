Detailed Description

Serializable tuning container for one Unity WheelFrictionCurve.

Stores inspector-editable friction curve values used by wheel colliders.

The values are copied into a WheelCollider friction curve by DriveTrainController. Keeping them in a struct makes the inspector safer than using positional float arrays.
