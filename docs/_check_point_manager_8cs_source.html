8/// </summary>

10/// @ingroup track_mng
11/// @brief Stores ordered <see cref="CheckPointListener"/> instances and provides helper methods for enabling,
12/// disabling, registering listeners, and rebuilding the checkpoint list from the scene.
13///
14/// This manager does not decide race progression by itself. It provides shared checkpoint operations for
15/// systems that need to activate checkpoints, deactivate them, listen to checkpoint claims, or discover all
16/// checkpoint listeners placed in the scene.
