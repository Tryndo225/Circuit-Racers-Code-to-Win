Detailed Description

Custom property drawer for polymorphic ButtonType managed references.

Renders a type-selection popup (for concrete subclasses) and the chosen instance's fields inline.

@thread Unity Editor thread only. Editor-only code; excluded from player builds. @usage Add a field like [SerializeReference] private ButtonType _action; on a component, then this drawer will allow choosing among non-abstract ButtonType subclasses and editing their serialized fields.
