30# Quick Start
31
321. **Start from the main menu**
33 - Choose **Play**, **Test Track**, or another available scene/action button.
34
352. **Choose or create a track**
36 - Pick a saved level from the level browser.
37 - Or generate a new track and inspect its preview.
38 - Keep the generated track to add it to your saved level list, or discard it and generate another one.
39
403. **Wait for the countdown**
41 - A full-screen countdown/respawn overlay appears before the car becomes active.
42
434. **Race**
44 - Follow the road.
45 - Pass checkpoints in order.
46 - Complete the required number of laps.
47 - The finish screen shows your final time.

51# Controls
52
53## Keyboard
54
55- **Throttle:** `W` or `Up Arrow`
56- **Brake / Reverse:** `S` or `Down Arrow`
57- **Steer Left / Right:** `A` / `D` or `Left Arrow` / `Right Arrow`
58- **Handbrake:** `Space`
59- **Lights Toggle:** `L`
60- **Menus / UI:** Mouse navigation
61- **Open unfinished result screen during race:** `Escape`
62
63## Gamepad
64
65- **Throttle:** Right Trigger
66- **Brake / Reverse:** Left Trigger
67- **Steer:** Left Stick X axis
68- **Handbrake:** South Button / Cross
69- **Lights Toggle:** D-Pad Up
70
71The vehicle controller detects the last used input device and uses that information to adjust steering behaviour.

75# HUD and What It Means
76
77## Countdown / Respawn Overlay
78
79A full-screen filter and timer appear before the race starts and during respawn.
80When the timer reaches zero, the car is live again.
81
82## Lap Time
83
84Shows the current lap's running time.
85
86## Track Time
87
88Shows the total elapsed track time.
89It is hidden until the first lap has started.
90
91## Lap Counter
92
93Shows race lap progress in the form:
94
95\code
96current / total
97\endcode
98
99Example:
100
101\code
1022/3
103\endcode
104
105## Checkpoint Counter
106
107Shows checkpoint progress through the current lap in the form:
108
109\code
110current / total
111\endcode
112
113Example:
114
115\code
1164/8
117\endcode
118
119## Checkpoint Split Popup
120
121When a checkpoint is passed, a temporary split popup may appear.
122It shows the current split time and the difference compared to the stored reference split.
123
124## Finish Screen
125
126When the race is complete, the finish screen shows the final race time.
127Pressing `Escape` during an unfinished race may open the result screen as unfinished.

131# Checkpoints, Laps, and Respawn
132
133## Checkpoints
134
135Checkpoints must be passed in order.
136Generated intermediate checkpoints are placed along suitable straight sections of the track.
137The placed start and finish blocks also provide checkpoint behaviour in the playable scene.
138
139## Laps
140
141Circuit tracks may require multiple laps.
142Point-to-point tracks end at a separate finish location.
143
144## Respawn
145
146The race system stores checkpoint-related state so the player can be returned to a fair recent position
147after crashes, resets, or race restarts.

151# Track Preview Colors
152
153The level preview uses simple colors to make the generated layout easy to read:
154
155- **Grass / Off-track:** green
156- **Road / Drivable track:** gray
157- **Start:** light-green marker
158- **Finish:** red marker
159- **Checkpoint:** light-blue marker
160
161For circuit tracks, the start and finish are represented by the same tile.

165# Level Generation
166
167The generator creates grid-based racing tracks.
168
169## Track Type
170
171- **Circuit:** the road closes back to the start.
172- **Point-to-point:** the road starts and finishes at different locations.
173
174## Size
175
176Width and height control the grid size.
177Larger maps can produce longer and more complex tracks.
178
179## Steps
180
181The step count controls how many times the generator attempts to extend the road.
182Higher values usually create longer or more varied tracks.
183
184## Preview
185
186A preview texture is generated before saving so the layout can be checked visually.
187
188Under the hood, generation uses flood-fill style path search, backtracking, spacer tiles, validation,
189and checkpoint post-processing to produce playable layouts.

216# Tips for Driving
217
218- Do not hold steering fully through every corner; smoother input is usually faster.
219- Brake before the corner, then steer.
220- Use the handbrake only when you need a sharp rotation.
221- Gamepad steering gives smoother analog control.
222- Watch checkpoint order and avoid cutting across the track.
223- Replays and saved best times are useful for comparing your improved runs.

227# Troubleshooting
228
229## No Input
230
231- Check that input actions are assigned.
232- If using automatic defaults, make sure default binding creation is enabled.
233- Press any keyboard or gamepad control to let the vehicle detect the active device.
234
235## No Sound
236
237- Make sure an AudioListener exists, usually on the main camera.
238- Check music, SFX, and engine volumes.
239- Check AudioMixer routing.
240- Check that the relevant clips are assigned.
241
242## Car Does Not Move
243
244- Check that the car prefab has a Rigidbody.
245- Check that all four WheelCollider references are assigned.
246- Check that at least one wheel is marked as powered.
247- Check that the wheels are touching a collider.
248
249## Lights Do Not Toggle
250
251- Check the lights input binding.
252- Check that the light lists contain valid Light references.
253- Check that the vehicle has a LightsController.
254
255## Missing Levels in Browser
256
257- Make sure the generated level was kept/saved from the popup.
258- Imported levels should be valid before being added to the saved list.
259
260## Low FPS with Large Tracks
261
262- Use smaller grid sizes.
263- Use fewer generation steps.
264- Avoid excessive preview/debug generation during gameplay.
