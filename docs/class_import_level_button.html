Detailed Description

Button strategy that imports a level from text entered into a TMP input field.

The input text is passed to ImportExportManager.TryImportLevelFromString. If the import succeeds, the popup is closed through ClosePopUpButton.Action. If the import fails, an error is logged and the popup remains open.
