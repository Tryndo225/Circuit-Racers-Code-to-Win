Detailed Description

Centralized scene loader and background-music router.

Loads scenes by helper or name, unpauses time, and selects a music clip based on a configured list of scene-to-clip pairs.

@thread Unity main thread only (Start, scene loads).

Invariant
SoundManager.Instance may be used to play music if available.
Each configured pair maps one scene (by name) to one AudioClip.
