Detailed Description

Simple popup controller that previews a generated LevelMap and lets the user accept (add to game data) or dismiss it.

Shows/hides a preview panel and forwards the map to GameDataManager when accepted.

Responsibilities:

  • Toggle a visual container on/off for the preview.
  • Drive a co-located LevelPreviewer to render the given LevelMap.
  • Add the accepted map to the persistent list via GameDataManager.AddLevel(LevelMap).

Threading:

  • Unity main thread only (standard MonoBehaviour lifecycle).

Usage:

  • Call ShowMap(LevelMap) with a generated map to display the popup preview.
  • Call KeepMap() to persist the currently previewed map; HideMap() to close.
