Detailed Description

Centralized audio service for background music and pooled 3D SFX playback, with per-clip continuation support and optional low-pass filtering on music.

@thread Unity main thread (Unity methods); audio rendering is on Unity’s audio thread.

Invariant
Exactly one active instance via Singleton<T>. @req SoundManagerHelper exists and exposes properties/methods used here: IsUsed, IsPlaying, Target, Clip, Volume, Pitch, SpatialBlend, Loop, and methods PlaySound(), PauseSound(), ResetSound(), StopSound().

float specialBlend = 0::0f,

inline

Plays (or reuses) a pooled SFX helper for the given clip at a target transform, with optional volume/pitch/loop and spatial blend control.

Parameters
clipClip to play (ignored if null).
transformWorld target whose position is tracked by the helper.
volumePer-call volume scalar (multiplied by global sfxVolume).
pitchPer-call pitch multiplier.
loopWhether the SFX should loop.
specialBlendSpatial blend for the helper [0..1]. 0 = 2D, 1 = fully 3D.
resetIf true and the clip is already playing, the helper is reset and restarted. If false, an already-playing clip continues uninterrupted.
