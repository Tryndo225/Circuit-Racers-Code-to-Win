Detailed Description

Serializable snapshot of the vehicle state at a specific replay time.

Stores one recorded replay sample, including transform, timing, lap, speed, steering, and snapshot type.

Snapshots are used by Replay to reconstruct or preview a recorded race over time. The Type field marks whether the snapshot is a normal fixed-update sample or an important replay event such as race start, checkpoint, or race end.
