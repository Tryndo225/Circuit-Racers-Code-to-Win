Detailed Description

Snapshot of race information displayed by RaceOverlay.

Transfers timing, counter, countdown, and finish-state data from a race state source to the HUD.

The overlay uses this struct so the UI does not need to know whether the data comes from normal gameplay, replay playback, or another implementation of RaceOverlaySource.
