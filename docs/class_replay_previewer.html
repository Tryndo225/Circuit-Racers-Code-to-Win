Detailed Description

Plays back recorded race replays by moving a replay car through recorded snapshots.

Instantiates or reuses a replay vehicle, samples ReplaySnapshot data over time, and updates replay playback state.

This component is responsible for previewing a recorded Replay. It advances replay time, interpolates between recorded snapshots, applies the interpolated position/rotation to a replay vehicle, updates replay wheel visuals when possible, and displays checkpoint split information through RaceOverlay.

The previewer can either instantiate a configured replay car prefab or use its own transform when no prefab is assigned.
