Detailed Description

Custom property drawer for editing TrackPieceRule entries in the Unity Inspector.

Provides a compact Rule-Tile-like editor for track-piece placement rules.

The drawer presents the regular rule fields, such as name, prefab, position offset, rotation, and pattern size, on the left side. On the right side it draws a clickable square pattern grid. Each grid cell cycles through the supported pattern states: empty, track, and checkpoint.

This editor-only class affects only how TrackPieceRule is displayed in the Inspector. It does not change the runtime placement logic directly.
