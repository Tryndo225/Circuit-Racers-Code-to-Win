Detailed Description

UI controller for the driving assist settings panel.

Synchronizes ABS and traction-control toggles with saved game settings.

This panel reads the current assist settings from GameDataManager when enabled and writes changes back through the public toggle callback methods.

Usage:

  • Assign absToggle and tcToggle in the Inspector.
  • Connect the toggles' OnValueChanged events to SetABS and SetTC.
  • The panel hides itself on start and can be opened by another UI button.
