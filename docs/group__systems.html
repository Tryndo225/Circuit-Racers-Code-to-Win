Topics

 Modular four-wheel car stack: input, drivetrain, transmission, audio, lights, VFX, collision SFX, and camera follow.
 Core Utilities
 Small shared helpers for commands, layer masks, content hashing, singletons, and serializable dictionaries.
 Game Data
 Persistent progression data, selected level state, best times, checkpoint splits, replays, and assist settings.
 Level Generation
 Procedural creation, representation, validation, and placement support for grid-based race tracks.
 Replay System

 Scene Management
 Centralized scene loading with editor-friendly scene references and scene-to-music pairing.
 Track Manager
 Race flow control (start/restart, laps, checkpoints, respawn) and player car spawning.

 Runtime UI widgets, menus, overlays, popups, settings, notifications, previews, and button actions.
