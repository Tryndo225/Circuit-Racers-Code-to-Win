Detailed Description

Manages race flow for a track with sequential checkpoints: spawns the player car, tracks laps and times, handles respawn/restart inputs, and advances checkpoint state.

Invariant
CheckPoints are ordered as the race path; index 0 is the start/finish for circuits.
If carPrefab is assigned, the spawned instance must include a Rigidbody.
When circuit mode is enabled (isCircuit), laps >= 1. @thread Unity main thread (lifecycle, physics callbacks, coroutines).
