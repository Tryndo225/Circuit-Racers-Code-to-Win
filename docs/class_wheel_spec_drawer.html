Detailed Description

Compact 1-row drawer for WheelSpec showing collider, visual, powered, and steering columns.

Purpose:

  • Presents a dense, horizontal layout for the four fields of WheelSpec in the Inspector.
  • Keeps the footprint to a single line per element for faster wheel setup.

Behavior:

  • Lays out four equal-width columns with a small padding: Collider | Visual | Powered | Steering.
  • Does not draw field labels (uses GUIContent.none); rely on column order and tooltips from Unity.

Threading:

  • Unity Editor thread only; compiled out of player builds with #if UNITY_EDITOR.

Notes:

  • Intended for use inside arrays or structs on vehicle setup components.
  • Pairs well with a header/tooltip on the parent field describing the column order.
