Detailed Description

High-level vehicle controller that connects player input to vehicle subsystems.

Wires input actions to drivetrain, transmission, engine audio, and lights.

This component acts as the main setup and coordination point for a playable vehicle. It owns the inspector-facing tuning values and pushes them into the specialized runtime components:

  • DriveTrainController for wheel physics and vehicle movement.
  • TransmissionController for RPM and shifting.
  • EngineSound for layered engine audio.
  • LightsController for vehicle lights.

Requirements:

  • Exactly four wheels should be configured in FL, FR, RL, RR order.
  • Each wheel entry should contain both a WheelCollider and a visual wheel transform.
  • A Rigidbody must be present on the same object.

Threading:

  • Unity main thread only.
  • Vehicle control is applied from FixedUpdate.
