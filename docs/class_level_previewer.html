Detailed Description

Renders a tiny top-down preview image of a LevelMap into a UI RawImage: grass background, road cells, checkpoint markers, and start/finish markers.

Lightweight, allocation-friendly level thumbnail generator for menus and lists.

Responsibilities:

  • Choose a pixels-per-cell (PPC) based on the target rect width and device max texture size.
  • Convert the integer tile grid into a CPU color buffer (on a worker thread).
  • Upload the buffer into a point-filtered Texture2D and assign it to the UI.

Threading:

  • CPU buffer generation is done off the main thread via Task.Run(Func<Task>).
  • Texture2D creation and assignment must occur on the Unity main thread (done after the await).

Performance notes:

  • Uses TextureFormat.RGBA32 and FilterMode.Point for crisp pixel art.
  • Avoid calling ShowPreviewAsync(LevelMap) every frame; call when data or size changes.

Asynchronously builds and displays a preview texture for the given map .

Parameters
mapLevel definition to visualize (must have valid Tiles, Width, Height).

The CPU color buffer is generated on a worker thread; the Texture2D is created and assigned on the main thread. PPC (pixels-per-cell) is chosen so the preview fits in the target rect and also respects SystemInfo.maxTextureSize.
