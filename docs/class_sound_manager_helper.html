Detailed Description

Lightweight pooled SFX helper owned by SoundManager.

Wraps a runtime AudioSource for pooled sound-effect playback.

This helper stores playback settings for one sound instance and applies them to an internal AudioSource. It can optionally follow a target Transform for positional 3D audio playback.

Behaviour:

  • If Loop is false, the helper automatically releases itself after playback finishes.
  • While Target is assigned, the helper follows the target position.
  • Runtime-adjustable values such as Volume, Pitch, and SpatialBlend are synchronized every frame.

Threading:

  • Unity main thread only.
