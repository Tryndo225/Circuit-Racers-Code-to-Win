Detailed Description

Click-dismissable UI popup used to display a notification message.

Represents the visual part of a notification shown by NotificationManager.

This component controls the displayed message text, text color, and popup alpha. It also implements IPointerClickHandler so the user can dismiss the current notification by clicking the popup.
