Detailed Description

Procedural engine audio controller using four RPM bands.

Blends idle, low, mid, and high RPM engine clips with on-throttle and off-throttle layers.

The component smooths RPM and throttle input, crossfades between four RPM bands, maps RPM to pitch, applies a short shift flare, and uses a soft limiter near redline.

Audio layout:

  • Four on-throttle layers: idle, low, mid, high.
  • Four off-throttle layers: idle, low, mid, high.
  • Each layer is played by its own looping AudioSource.

Threading:

  • Unity main thread only.
  • Updated from Update.
