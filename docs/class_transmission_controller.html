Detailed Description

Simple automatic transmission controller for a vehicle.

Computes engine RPM from wheel RPM, handles automatic gear changes, and exposes shift callbacks.

The controller maps driven-wheel RPM through the current gear ratio and final drive to estimate engine RPM. It then shifts up or down based on configured RPM thresholds, as long as wheel slip is below the configured slip threshold.

Behaviour:

  • Keeps track of the current forward gear.
  • Calculates clamped engine RPM.
  • Starts upshift/downshift coroutines when thresholds are reached.
  • Temporarily reports torque cut while shifting.
  • Invokes registered shift callbacks when a shift starts.

Requirements:

  • forwardGears should contain at least one gear ratio.
  • idleRPM should be less than or equal to redlineRPM.
  • shiftDownRPM should usually be lower than shiftUpRPM.

Threading:

  • Unity main thread only.
  • Shift timing uses Unity coroutines.
