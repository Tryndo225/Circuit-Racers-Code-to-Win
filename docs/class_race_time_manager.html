Detailed Description

Manages race timing, lap timing, checkpoint splits, and race completion.

Tracks race progress times and forwards completed race data to replay and game-data systems.

This manager records:

  • Race start time.
  • Lap start and lap durations.
  • Checkpoint split times.
  • Final race time.

It also connects checkpoint events to split recording, starts replay recording when the race begins, saves the replay when the race ends, and passes completed race results to GameDataManager.
