Detailed Description

Trigger-based checkpoint sensor that captures the player's pose and velocities on entry and notifies registered listeners.

Intended for lap/track progression and respawn points.

Invariant
A Collider (set to trigger) and a Renderer exist on the same GameObject (enforced by attributes; validated in GetReferences). @thread Unity main thread only (standard MonoBehaviour lifecycle). @usage
  • Call SetActive(bool) to enable/disable the checkpoint (toggles collider & renderer).
  • Register callbacks with AddListener(Action) to react when the player enters the trigger.
  • After a claim, read the captured respawn data via cPClaimedPosition, cPClaimedRotation, cPClaimedRbLinearVelocity, and cPClaimedRbAngularVelocity.
